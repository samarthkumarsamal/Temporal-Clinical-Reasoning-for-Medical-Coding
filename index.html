Temporal Clinical Reasoning for Medical Coding.

Predicting ICD diagnosis codes and CPT procedure codes from clinical notes recorded across a hospital admission.

The project organizes a patient's notes in time order instead of using only one document. Each note is encoded with BioClinicalBERT, and the sequence is modeled to predict ICD and CPT codes for the admission.

Project overview

Clinical information is spread across multiple notes.

A patient's diagnosis and treatment information can appear in different notes at different times. This project keeps that order when building the model input.

Abstract

Using multiple notes from the same admission

This project predicts ICD diagnosis codes and CPT procedure codes from clinical records. A single discharge summary may not contain all relevant information, so we also use notes created earlier in the admission.

We compare three approaches: BioClinicalBERT using one discharge summary, Longformer using combined documents, and BioClinicalBERT + bidirectional LSTM using notes in chronological order.

The temporal model uses the sequence of notes to predict ICD and CPT codes together.

Problem

One document may miss earlier information

Relevant information can appear in radiology reports, nursing notes, and the discharge summary at different times during the stay.

Objective

Keep the order of clinical notes

Group notes by admission, sort them by time, and use the ordered sequence to predict diagnosis and procedure codes.

System overview

Project framework.

Clinical notes are grouped by admission and sorted by time before they are passed to the model.

Methodology

Three models for medical code prediction.

The models use progressively more information: one discharge summary, combined documents, and then notes kept in chronological order.

01 Baseline 1

BioClinicalBERT

One discharge summary

  • Matches notes and labels using hadm_id.
  • Uses one discharge summary per admission.
  • Adds dropout and a linear classification head to BioClinicalBERT.
  • Uses 86,146 admissions with a 60,302 / 12,922 / 12,922 train-validation-test split.
BioClinicalBERT Single Note Multi-label
02 Baseline 2

Longformer

Combined discharge and radiology notes

  • Groups discharge and radiology documents by hadm_id.
  • Sorts documents using charttime.
  • Merges documents into a single long text input.
  • Uses Longformer to handle the longer combined text input.
Longformer Long Context Multi-document
03 Proposed temporal model

BioClinicalBERT + BiLSTM

Notes ordered by time

  • Sorts clinical notes chronologically within each admission.
  • Uses up to five notes as the admission-level sequence.
  • Encodes each document with BioClinicalBERT.
  • Uses a single-layer bidirectional LSTM across the ordered note embeddings.
  • Uses 101,655 admissions with a 71,158 / 15,248 / 15,249 train-validation-test split.

FINDING 01

The temporal model improves on the single-note baseline

Using multiple notes in time order improves the temporal model over the single-discharge-summary BioClinicalBERT baseline.

FINDING 02

Longformer has the best joint score

Longformer reaches the highest joint score and the best ICD Micro-F1 and Macro-F1.

FINDING 03

The temporal model performs best on CPT metrics

The temporal model has the highest CPT Micro-F1, CPT Macro-F1, and CPT Precision@5.

FINDING 04

Rare ICD codes are still difficult

Less frequent ICD codes are harder to predict because the labels are imbalanced and the current sequence model has limited long-range context.

Research outlook

Limitations and next steps.

The current model works with a limited number of notes and still struggles with rare codes. These are the main areas for improvement.

Current limitations

Current limitations

  • Rare-code prediction remains limited by label imbalance.
  • Each admission is represented by a limited number of notes.
  • Longer hospital stays can lose useful information through truncation.
  • The LSTM-based sequence model may not fully capture distant long-range dependencies.

Future work

Planned improvements

  • Incorporate structured clinical data together with free-text note representations.
  • Improve rare-code prediction using stronger sampling strategies.
  • Explore transformer-based temporal architectures for longer clinical sequences.
  • Use more notes from long admissions without making training too expensive.
