Project overview

Why temporal context matters in medical coding

The limitation

Existing automated coding systems often rely on a single document, such as a discharge summary. That can miss clinically important information distributed across radiology reports, nursing notes, and other records created throughout an admission.

Our direction

We organize clinical notes at the admission level, preserve their chronological order, encode each note with BioClinicalBERT, and model the evolving patient state with a bidirectional LSTM for joint ICD and CPT prediction.

Abstract

From isolated documents to longitudinal reasoning

This project focuses on predicting ICD diagnosis codes and CPT procedure codes from clinical records. To better use information distributed across a patient's admission, the project compares a single-document BioClinicalBERT baseline, a Longformer-based multi-document model, and a temporal BioClinicalBERT + BiLSTM model.

The temporal model processes multiple notes in chronological order, capturing dependencies across documents and enabling joint medical code prediction within a unified multi-label framework.

05

Research outlook

Limitations and future work

Current limitations
  • Rare-code performance remains limited by label imbalance.
  • Only a limited number of notes are retained per admission.
  • LSTM may not fully capture distant long-range dependencies.
  • Information compression can reduce some ICD performance.
Next directions
  • Integrate structured clinical data with note representations.
  • Improve rare-code learning with stronger sampling strategies.
  • Explore transformer-based temporal sequence models.
  • Model longer admissions without aggressive truncation.
